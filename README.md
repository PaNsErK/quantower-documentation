# Inoffizielle Quantower-Dokumentation

Öffentliche, **inoffizielle** und nicht-tradende Dokumentation für Quantower-Komponenten. Der aktuelle Schwerpunkt ist **Fractal Zones v2**.

Status: `public_beta_user_evaluation_pending`

- `runtime_acceptance_complete=false`: Die historische V1–V4-Laufzeitevidenz bleibt erhalten; die aktuellen FZCP-v5- und FZCP-v6-Suites stehen bewusst auf `sourceValidatedRuntimePending`.
- `manual_acceptance_complete=false`: Die abschließende Benutzerabnahme ist nicht abgeschlossen.
- `user_evaluation=pending_user_evaluation`: Lokale Lern-, historische Remediation- und aktuelle V5/V6-Matrizen sind getrennt.

Die Website funktioniert online und offline ohne Analytics, Telemetrie, Remote-Fonts, CDN-Skripte oder Runtime-Netzwerk-API. Lokaler Testfortschritt bleibt im Browser und wird nur auf ausdrücklichen Wunsch exportiert.

## Lokal prüfen

```text
python tools/run_documentation_update.py
```

Das Projekt enthält keine Quantower-Binärdateien, privaten Quelltexte, Rohlogs oder Trading-Daten.
